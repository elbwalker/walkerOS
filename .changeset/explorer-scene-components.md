New design components for walk-throughs and posts: `TitleCover`, `Slide`,
`Captions`, `StepMarker`, `EndCard` and `Terminal`, built on the design tokens.
`TaggingViz` shows markup being tagged, the element lighting up and the events
it sends, from a script and a time; the home page demo now runs on it, a caller
can show some of its panes (`panes`), and a long line wraps at a space. The
static code view can mark lines, number them and type the whole code or one line
inside it (`typing`).
