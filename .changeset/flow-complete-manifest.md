The canonical example `flow-complete.json` is rewritten as one tested ecommerce
setup with web, server and warehouse flows, and comes with a 15-chapter guide.
The new `flowCompleteManifest` export from `@walkeros/cli/examples` names every
feature by a stable id with a JSON Pointer into the file, so docs and tools can
reference it.
