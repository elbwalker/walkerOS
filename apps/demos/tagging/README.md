# walkerOS tagging demo

A static one-page shop tagged with walkerOS `data-elb` attributes. It runs at
https://tagging.walkeros.io and is deployed from `main` by
`.github/workflows/tagging.yml`.

To run it locally, run `npm install` and `npm start` in this folder.
`index.html` loads the walker.js of the demo flow from the walkerOS CDN.
