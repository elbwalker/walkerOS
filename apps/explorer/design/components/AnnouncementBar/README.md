Full-width `primary` strip above the header announcing the latest release.

Use one per page, at the very top, for release news only. Text is `small` 14px/600 in `on-primary`; the link inherits the colour and stays underlined.

**Consumer provides:** `children` (the message), optional `linkLabel` + `href`.

- Do: "What's new: Just shipped v4.6 · Read the release notes".
- Don't: stack promos, add icons, or put white text on it.
