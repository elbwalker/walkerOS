Tagging feature demo: one `ArticleTeaser` tagged once, walked through atom → molecule → organisms → pages, showing how every instance inherits entity, action, properties, context and globals.

Five steps (Atom, Molecule, HomeFeed, RelatedStories, Pages) reveal the code on the left while the rendered home feed and related-stories cards pick up their outlines and pills on the right. Autoplay starts when the code pane scrolls 35% into view; clicking a step jumps to it. The legend and caption explain each step.

**Consumer provides:** optional `autoplay` (default true), `speed` (default 1), `initialStep` (1–5, shows that step fully revealed).

Stays dark in both themes. Wording of the captions follows the walkerOS nouns: entity, action, context, globals.
