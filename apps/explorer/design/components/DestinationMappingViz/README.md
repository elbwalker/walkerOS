Mapping feature demo: pick one `elb()` event and see the mapping rule and the exact call it produces in GA4, Meta Pixel, TikTok Pixel and Amplitude.

Three event chips (`product view`, `lead submit`, `order complete`); the selected chip takes a `primary` border. Each destination card shows its `mapping` rule and what it `sends`, with the mapped name highlighted in entity green. A closing caption states the payoff.

**Consumer provides:** optional `initialEvent` (0–2), `caption` (string, or `''` to hide).

Interactive, no autoplay. Stays dark in both themes.
