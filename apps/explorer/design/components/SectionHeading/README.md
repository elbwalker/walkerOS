Eyebrow, heading and optional lead — the opening of every section, or the hero when `level` is 1.

Eyebrow is `eyebrow` in `link`; H2 is `heading-lg`; H1 is `display` with an optional `highlight` phrase in `primary`. Max width 760px (hero centered, 20ch heading).

**Consumer provides:** `title`, optional `eyebrow`, `lead`, `level` (1 | 2), `highlight` (H1 only), `align`.

The eyebrow names the problem; the heading states the outcome in two short beats.
