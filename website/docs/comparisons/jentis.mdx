[Jentis](https://www.jentis.com/) is a managed server-side tracking platform
from Austria, focused on privacy compliance and data recovery.

## Quick comparison

| Feature              | Jentis                    | walkerOS                          |
| -------------------- | ------------------------- | --------------------------------- |
| Open-source          | No                        | Yes                               |
| Pricing              | From €490/month           | Free (paid support available)     |
| Self-hosted option   | No (managed only)         | Yes                               |
| Server-side tracking | Yes                       | Yes                               |
| Vendor lock-in       | Yes                       | None                              |
| Data ownership       | Jentis servers (EU)       | Your infrastructure               |
| Built-in connectors  | 100+ managed              | Build your own or use existing    |
| AI/Synthetic data    | Yes ("Synthetic Users")   | No                                |
| Setup complexity     | Low (fully managed)       | Medium (self-hosted)              |

## Who should use what?

### Choose Jentis if

- You want a fully managed, hands-off solution
- Budget isn't a constraint (starting at €490/month)
- You prefer vendor support over self-management
- You need their "Synthetic Users" AI feature for data modeling
- You want 100+ pre-built connectors without building integrations

### Choose walkerOS if

- You want full control and code transparency
- You prefer open-source with no vendor lock-in
- You want to self-host on your own infrastructure
- Cost matters (walkerOS is free)
- You're developer-focused and want config-as-code workflows
- You need flexibility to build custom destinations

## Key differences

### Cost

**Jentis:** The Advanced plan starts at €490/month. Premium and AI-powered tiers
require custom pricing, and enterprise costs can scale significantly.

**walkerOS:** The software is free and open-source, and you pay for your own
infrastructure. Optional paid services include implementation support (setup
fees) and SLAs for teams that want help getting started or need guaranteed
support.

### Hosting model

**Jentis:** Managed service only. Jentis hosts and maintains everything, so you
don't have to run your own servers, and you can't choose to.

**walkerOS:** Self-hosted by default. You control where your data lives and how
your infrastructure scales, which also makes you responsible for both.

### Transparency

**Jentis:** Proprietary and closed-source. You have to trust their
implementation because you can't audit the code.

**walkerOS:** Fully open-source. You can audit the code, see exactly what
happens, and contribute improvements.

### Flexibility

**Jentis:** A managed platform with pre-built connectors, which works well if
their integrations cover your needs.

**walkerOS:** You can create custom destinations for any API, data warehouse, or
internal system.
