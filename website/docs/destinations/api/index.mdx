transformation.

## Environments

| Environment  | Package                            | Use Case                       |
| ------------ | ---------------------------------- | ------------------------------ |
| **Web**      | `@walkeros/web-destination-api`    | Browser-side with fetch/XHR/beacon |
| **Server**   | `@walkeros/server-destination-api` | Node.js with native HTTP       |

## Quick Start

Choose your environment:

- [Web (Browser)](/docs/destinations/api/web) - fetch, XHR, beacon transports
