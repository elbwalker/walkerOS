# Code Destination

A destination does not need a package. Pass an object with a `push` function
as `code`, and the collector calls it for every event, like any other
destination. Use it to run a few lines of your own code on events.

## Integrated

<CodeSnippet
  code={`import { startFlow } from '@walkeros/collector';

const { elb } = await startFlow({
  destinations: {
    console: {
      code: {
        type: 'console',
        config: {},
        push: (event) => {
          console.log('Event:', event.name, event.data);
        },
      },
    },
  },
});`}
  language="typescript"
/>

## Bundled

In a `flow.json`, write the function as a `$code:` string:

<CodeSnippet
  code={`"destinations": {
  "console": {
    "code": {
      "type": "console",
      "push": "$code:(event) => { console.log('Event:', event.name, event.data); }"
    }
  }
}`}
  language="json"
/>

The rules for `code` in a flow file are in
[Inline code](/docs/getting-started/flow#inline-code-without-packages).

Set `consent`, `mapping` and the other destination options in `config` beside
`code`, as for any destination. In integrated mode the object can implement the
whole [destination interface](/docs/destinations/create-your-own). `batch`
needs a `pushBatch` function, which only the integrated form can provide: a
flow file's `code` takes only `type`, `init` and `push`.
