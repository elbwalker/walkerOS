# Heap

<PackageLink

[Heap](https://www.heap.io/) (now part of Contentsquare) is a product
analytics platform with auto-capture and retroactive event definitions.
With `loadScript: true`, this destination loads the Heap script from Heap's
CDN. It forwards walkerOS events through `heap.track(name, properties)`, plus
identity, user properties, persistent event properties, and runtime consent.

:::caution
`loadScript: true` loads the classic Heap SDK
(`https://cdn.heapanalytics.com/js/heap-<appId>.js`). Events pushed while the
script loads wait for it and reach Heap once it is ready; if the script is
blocked or fails to load, those and later pushes fail with `vendor-not-loaded`
and show up as failed events. `disableTextCapture` (default `true`),
`secureCookie` and further SDK options in `heapConfig` go into the config the
classic SDK reads when it loads, so they apply only with `loadScript: true`.
Without `loadScript` the destination ignores them and nothing reports it: set
these options in your own Heap snippet. The classic SDK has no switch to stop
tracking, so a consent revocation stops the events walkerOS sends but not
Heap's own autocapture (see Consent).
:::

## Consent

With `config.consent` declared, the collector initializes the destination, and
with `loadScript: true` loads Heap's script, only once one of the required
consent keys is granted (see [consent management](/docs/guides/consent)). On
each consent command that names a required key, once Heap has loaded, the
destination calls `heap.startTracking()` while the required consent is granted
(one granted key is enough) and `heap.stopTracking()` otherwise.

The classic SDK that `loadScript: true` loads has neither method, so the
destination calls neither. A revocation then only stops the events walkerOS
sends: Heap's own autocapture keeps running because the classic SDK cannot be
switched off. To keep Heap from capturing
before consent, load Heap's script only after consent is granted, which is what
`config.consent` does with `loadScript: true`.

<CodeSnippet
  code={`destinations: {
  heap: {
    code: destinationHeap,
    config: {
      loadScript: true,
      consent: { analytics: true },
      settings: { appId: 'YOUR_HEAP_APP_ID' },
    },
  },
}`}
  language="typescript"
/>
