# Piano Analytics

[Piano Analytics](https://piano.io/product/analytics/) is an enterprise
analytics and audience platform. The destination configures the official Piano
`pa` SDK with your site id and collection domain, and forwards events via
`pa.sendEvent`. With `loadScript: true` it also loads the SDK.

## Loading the SDK

With `loadScript: true`, the destination adds the SDK script
`https://tag.aticdn.net/piano-analytics.js` and, once the script has loaded,
configures `pa` with `site`, `collectDomain` and `options` before its first
event. Events pushed while the script loads wait for it, including the page
view a browser source sends when the flow starts. If the script is blocked,
the waiting and later pushes fail. If it has not loaded within the
destination's `timeout` (10 seconds by default), the waiting pushes fail, and
later ones until the script has loaded. A failed push lists the destination
under `failed` in the push result, and the log shows an ERROR line. A missing `site` or `collectDomain`
fails the destination with a `config` error, and a rule with `silent: true`
sends no event.

If Piano's SDK is already on your page before walkerOS starts, leave
`loadScript` unset. The destination then configures `pa` before its first
event; without `pa` on the page, pushes fail with `vendor-not-ready`.

## Event names

Each rule's `name` becomes the Piano event name and its `data` object the event
properties, as in the examples above. Without a rule, the destination sends the
walkerOS event name, like `page view`, with no properties.
