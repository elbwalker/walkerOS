# Plausible Analytics

<PackageLink
  env="web"
  github="packages/web/destinations/plausible"
  npm="@walkeros/web-destination-plausible"
/>

[Plausible Analytics](https://plausible.io/) is a simple, privacy-friendly
Google Analytics alternative. With `loadScript: true` the destination loads
Plausible's manual script (`script.manual.js`) for your `domain`. It installs
the `plausible` queue function and sends each event as `plausible(name, data)`.

## Page views and custom events

The manual script records no page view by itself. Plausible counts a page view
for an event named `pageview`, so the example above maps `page view` to it.
Without that rule, a walkerOS `page view` reaches Plausible as a custom event
named `page view`.

Every other event is a custom event named after the rule's `name`, or the
walkerOS event name. Plausible accepts custom properties with scalar values
only (strings, numbers, booleans) under `props`, and revenue as
`{ currency, amount }`, as the examples above show.

Without `loadScript`, the calls wait in the `plausible` queue until a Plausible
script on your page processes them.
