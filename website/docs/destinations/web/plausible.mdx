# Plausible Analytics

<PackageLink

[Plausible Analytics](https://plausible.io/) is a simple, privacy-friendly
Google Analytics alternative. With `loadScript: true` the destination loads
Plausible's manual script (`script.manual.js`) for your `domain`; without a
`domain` it fails with a `config` error, because Plausible counts each event
for that domain. It installs the `plausible` queue function and sends each
event as `plausible(name, data)`.

## Installation

<Quickstart data={data} />

Plausible counts a page view only for an event named `pageview`, and the manual
script records none by itself: add
`"mapping": { "page": { "view": { "name": "pageview" } } }` to the destination's
`config`. Without it, a walkerOS `page view` reaches Plausible as a custom event
named `page view`.

<Configuration type="destination" data={data} />

## Page views and custom events

Apart from the `pageview` rule above, every event is a custom event named after
the rule's `name`, or the walkerOS event name. Plausible accepts custom
properties with scalar values only (strings, numbers, booleans) under `props`,
and revenue as `{ currency, amount }`, as the examples above show.

Without `loadScript`, the calls wait in the `plausible` queue until a Plausible
script on your page processes them.
