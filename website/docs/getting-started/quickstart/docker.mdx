# Docker

Build a flow with the CLI, then run it in the `walkeros/flow` image. The image
runs prebuilt artifacts only, so every Docker path starts with
`walkeros bundle`.

## 1. Write a flow

Save as `flow.json`: an HTTP endpoint at `/collect` that logs every event it
receives.

<CodeSnippet
  code={`{
  "version": 4,
  "flows": {
    "default": {
      "config": {
        "platform": "server",
        "bundle": {
          "packages": {
            "@walkeros/collector": { "version": "latest", "imports": ["startFlow"] },
            "@walkeros/server-source-express": { "version": "latest" },
            "@walkeros/destination-demo": { "version": "latest" }
          }
        }
      },
      "sources": {
        "http": {
          "package": "@walkeros/server-source-express",
          "primary": true,
          "config": { "settings": { "path": "/collect", "port": 8080, "cors": true } }
        }
      },
      "destinations": {
        "demo": {
          "package": "@walkeros/destination-demo",
          "config": { "settings": { "name": "Demo" } }
        }
      }
    }
  }
}`}
  language="json"
/>

## 2. Bundle it

<CodeSnippet code={`npx @walkeros/cli bundle flow.json -o dist/`} language="bash" />

This writes the artifact directory `dist/`: `flow.mjs`, `package.json` and
the traced `node_modules/`.

## 3. Run it

<CodeSnippet
  code={`docker run --rm -p 8080:8080 \\
  -v "$PWD/dist:/app/flow:ro" \\
  walkeros/flow:<version>`}
  language="bash"
/>

Replace `<version>` with a `walkeros/flow` version that ships `runneros`,
ideally the CLI version you bundled with, see
[image tags](/docs/apps/runtime#image-tags). The image starts
`/app/flow/flow.mjs` by default, so the mount is all it needs.

## 4. Send an event

<CodeSnippet
  code={`curl http://localhost:8080/ready

curl -X POST http://localhost:8080/collect \\
  -H "Content-Type: application/json" \\
  -d '{"name":"page view","data":{"title":"Home"}}'`}
  language="bash"
/>

`/ready` answers `{"status":"ready"}` once the flow is up, and the container
log shows the event arriving at the demo destination.

## Bake it into an image

For deployment, build the artifact inside a multi-stage Dockerfile so the
image carries it. Use the
[canonical Dockerfile](/docs/apps/runtime#canonical-dockerfile).

## Docker Compose

<CodeSnippet
  code={`services:
  walkeros:
    image: walkeros/flow:<version>
    volumes:
      - ./dist:/app/flow:ro
    ports:
      - '8080:8080'
    restart: unless-stopped`}
  language="yaml"
/>
