# Deploy walkerOS to GCP Cloud Run

This guide deploys a walkerOS flow to Google Cloud Run, forwarding events to BigQuery.

## Prerequisites

- [Docker](https://docs.docker.com/get-docker/) installed (for local testing)
- [Node.js 18+](https://nodejs.org/) installed

## 1. Set Up BigQuery

Follow the <Link to="/docs/destinations/server/gcp#gcp-setup">GCP BigQuery setup</Link> to:

- Create a BigQuery dataset
- <Link to="/docs/destinations/server/gcp#create-service-account">Create a service account</Link> with write permissions
- <Link to="/docs/destinations/server/gcp#create-table-query">Create the events table</Link>

For local testing, <Link to="/docs/destinations/server/gcp#service-account-key">download a service account key</Link>. Production uses <Link to="/docs/destinations/server/gcp#workload-identity">Workload Identity</Link>.

### Enable Cloud Run API

```bash
gcloud services enable run.googleapis.com
```

## 2. Bundle the Flow

Install the CLI and bundle the flow:

```bash
npm install -g @walkeros/cli

# Bundle the flow
walkeros bundle https://www.walkeros.io/flows/gcp-bigquery.json -o dist/
```

This creates the artifact directory `dist/`: `flow.mjs`, `package.json` and
the traced `node_modules/`. Add a `dist/Dockerfile` that copies the whole
directory into the runtime image:

```dockerfile
FROM walkeros/flow:<version>
COPY . /app/flow/
```

Replace `<version>` with the `walkeros/flow` version matching your CLI, see
[image tags](/docs/apps/runtime#image-tags). The image starts
`/app/flow/flow.mjs` on port 8080 by default. To bundle inside Docker instead,
use the [canonical two-stage Dockerfile](/docs/apps/runtime#canonical-dockerfile).

:::note Environment variables are read at runtime
This is a server flow, so its `$env.NAME` references are not baked into the
bundle: the built flow reads them from the container's environment when it
starts. Required: `GCP_PROJECT_ID`. Optional with defaults: `BQ_DATASET`
(walkerOS), `BQ_TABLE` (events), `BQ_LOCATION` (EU). Only web flows bake
`$env` values in, from `config.bundle.env`.
:::

## 3. Test Locally with Docker

Before deploying, verify everything works locally:

```bash
# Run locally (uses key file for auth)
docker run --rm \
  -p 8080:8080 \
  -v "$(pwd)/dist:/app/flow:ro" \
  -v $(pwd)/sa-bigquery.json:/app/sa-bigquery.json:ro \
  -e GOOGLE_APPLICATION_CREDENTIALS=/app/sa-bigquery.json \
  -e GCP_PROJECT_ID=your-project-id \
  walkeros/flow:<version>
```

In another terminal, send a test event:

```bash
curl -X POST http://localhost:8080/collect \
  -H "Content-Type: application/json" \
  -d '{
    "name": "page view",
    "data": {
      "title": "Test Page",
      "path": "/test"
    }
  }'
```

Expected response:

```json
{ "success": true, "timestamp": 1234567890 }
```

Check BigQuery for the event:

```bash
bq query --use_legacy_sql=false \
  "SELECT * FROM walkerOS.events WHERE DATE(timestamp) = CURRENT_DATE() ORDER BY timestamp DESC LIMIT 5"
```

## 4. Deploy to Cloud Run

Cloud Run builds the image from `dist/Dockerfile`. It uses Workload Identity, so no credentials file is needed in the image.

Deploy with the service account attached:

```bash
cd dist

gcloud run deploy walkeros-flow \
  --source . \
  --port 8080 \
  --region europe-west1 \
  --allow-unauthenticated \
  --service-account=walkeros-flow@YOUR_PROJECT_ID.iam.gserviceaccount.com \
  --set-env-vars GCP_PROJECT_ID=YOUR_PROJECT_ID \
  --memory 512Mi \
  --cpu 1 \
  --min-instances 0 \
  --max-instances 10
```

Note the service URL from the output (e.g., `https://walkeros-flow-xxx-ew.a.run.app`).

## 5. Verify Deployment

### Health Check

```bash
curl https://walkeros-flow-xxx-ew.a.run.app/health
```

### Send Test Event

```bash
curl -X POST https://walkeros-flow-xxx-ew.a.run.app/collect \
  -H "Content-Type: application/json" \
  -d '{
    "name": "page view",
    "data": {
      "title": "Production Test",
      "path": "/"
    }
  }'
```

### Query BigQuery

```bash
bq query --use_legacy_sql=false \
  "SELECT name, data, timestamp FROM walkerOS.events WHERE DATE(timestamp) = CURRENT_DATE() ORDER BY timestamp DESC LIMIT 5"
```

To remove all created resources:

- Delete the Cloud Run service (`gcloud run services delete walkeros-flow --region europe-west1`)

- Delete local files (`dist/`, `sa-bigquery.json`)
