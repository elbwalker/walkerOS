# CookieFirst

Integrates [CookieFirst](https://cookiefirst.com/) consent management with walkerOS by listening for CookieFirst events and translating consent categories to walkerOS consent groups.

## Installation

```bash
npm install @walkeros/web-source-cmp-cookiefirst
```

```typescript
import { startFlow } from '@walkeros/collector';
import { sourceCookieFirst } from '@walkeros/web-source-cmp-cookiefirst';

await startFlow({
  sources: {
    consent: {
      code: sourceCookieFirst,
    },
  },
});
```

## How it works

1. **Initialization**: Checks if CookieFirst is already loaded and processes
   existing consent state from `window.CookieFirst.consent`.

2. **cf_init event**: Listens for the `cf_init` window event and reads
   `window.CookieFirst.consent` each time it fires.

3. **cf_consent event**: Listens for the `cf_consent` window event and
   processes the consent state in its `detail`.

4. **Consent mapping**: Translates CookieFirst categories to walkerOS consent
   groups and calls `elb('walker consent', state)`.

### Default category mapping

```typescript
{
  functional: 'functional',
  performance: 'analytics',
  advertising: 'marketing',
}
```

`necessary` has no entry and is reported as `necessary`: strictly necessary
cookies need no consent, so they grant no consent group, and `functional`
follows the visitor's choice for the `functional` category. Categories missing
from `categoryMap` are reported under their CookieFirst name.

When several categories map to the same group, the group is `true` only if
every one of them is granted: any deny denies. Category names are compared
case-insensitively.

The source reports nothing while `window.CookieFirst.consent` is `null`, that
is until the visitor has made a choice.

### Custom mapping example

```typescript
await startFlow({
  sources: {
    consent: {
      code: sourceCookieFirst,
      config: {
        settings: {
          categoryMap: {
            performance: 'statistics', // Use 'statistics' instead of 'analytics'
          },
        },
      },
    },
  },
});
```
