## How it works

The dataLayer source intercepts `dataLayer.push()` calls and transforms them into walkerOS events:

1. Intercepts existing `dataLayer.push()` calls
2. Filters entries with an optional `filter` function
3. Transforms each entry into a walkerOS event named `"<prefix> <event>"`
4. Forwards the event to the collector for processing

<CodeSnippet
  code={`// Existing dataLayer code (unchanged)
window.dataLayer = window.dataLayer || [];
dataLayer.push({ event: 'purchase', value: 99.99 });

// Captured by sourceDataLayer as the event "dataLayer purchase"
// with data { value: 99.99 }`}
  language="javascript"
/>

An event carries only the values of its entry: strings, numbers, booleans,
`null`, and objects and arrays of them, with a date as its timestamp in
milliseconds. Functions such as `eventCallback`, DOM elements such as
`gtm.element`, `undefined` and keys whose getter throws are left out. A value
reached again through a cycle is left out, and once an entry contains a cycle,
every later repeated reference in it is dropped too (`items: [p, p]` becomes
`[p]`); in an entry without a cycle, an object referenced twice is kept twice,
as JSON keeps it. The page's own `dataLayer.push` always runs and never throws
because of the source.

The source reads the page's `window` and needs no `env`, in integrated and
bundled mode alike. In tests, `env.window` replaces it.

Every event carries the page context in `source`, like browser source events:
`{ type: 'dataLayer', platform: 'web', url, referrer }`, with `url` from
`window.location.href` and `referrer` from `document.referrer`. Both are read
when the event is emitted, so a push after an SPA navigation carries the new
URL, and entries queued before the source started get the URL at replay time.
Server destinations that read `source.url` (such as Meta Conversions API or
Piwik PRO) use it for dataLayer events without extra config.

## Custom filtering

`filter` is called with each dataLayer entry before it becomes an event and
returns `true` to skip it. This filter keeps only `purchase` and `add_to_cart`
objects:

<CodeSnippet
  code={`const { elb } = await startFlow({
  sources: {
    dataLayer: {
      code: sourceDataLayer,
      config: {
        settings: {
          filter: (entry) => {
            const name =
              typeof entry === 'object' && entry !== null && 'event' in entry
                ? entry.event
                : undefined;
            // true skips the entry
            return name !== 'purchase' && name !== 'add_to_cart';
          },
        },
      },
    },
  },
});`}
  language="typescript"
/>

The entry is the raw value: an object for `dataLayer.push({ event: ... })`, the
`arguments` of the call for `gtag(...)`. The filter must return synchronously: a
returned Promise is not awaited and the entry is processed. A filter that
throws keeps the entry.

## Source-level mapping

The source emits walkerOS events whose `name` is `"<prefix> <gtag-action>"`. The collector splits `name` on the first space into `entity` and `action`, so the prefix becomes the entity and the gtag action becomes the action. Source-level mapping rules key on that pair. At a source a rule renames the event (`name`) and edits it with `policy`; policy values resolve against the event, so the gtag fields are under `data.`, and a `data` entry in `policy` replaces the event's data with the mapped object:

<CodeSnippet
  code={`"sources": {
  "dataLayer": {
    "package": "@walkeros/web-source-datalayer",
    "config": {
      "settings": { "prefix": "dataLayer" },
      "mapping": {
        "dataLayer": {
          "add_to_cart": {
            "name": "product add",
            "policy": {
              "data": {
                "map": {
                  "id": "data.items.0.item_id",
                  "name": "data.items.0.item_name",
                  "price": "data.value",
                  "currency": "data.currency",
                  "quantity": "data.items.0.quantity"
                }
              }
            }
          },
          "purchase": {
            "name": "order complete",
            "policy": {
              "data": {
                "map": {
                  "id": "data.transaction_id",
                  "value": "data.value",
                  "currency": "data.currency"
                }
              }
            }
          }
        }
      }
    }
  }
}`}
  language="json"
/>

For the gtag commands `consent`, `config`, and `set`, the action equals the command name (any trailing token such as `update` or a measurement ID is dropped by the entity/action split). Branch on the dropped value via rule-level `condition` or `event.data` if you need to distinguish, for example, `consent default` from `consent update`.

If you set a custom `prefix` (for example `"gtag"`), use that string as the entity key: `mapping.gtag.add_to_cart`.

A `data` key in a source rule does nothing: `walkeros validate` rejects it, and the collector logs one ERROR line when the source registers. See [source mapping](/docs/mapping/rule#source-mapping) for what applies at a source.

## Migration strategy

Use the dataLayer source for gradual migration from GA4/GTM:

### Phase 1: Add walkerOS alongside existing dataLayer

<CodeSnippet
  code={`// Existing code continues to work
dataLayer.push({ event: 'purchase', value: 99.99 });
// Now also captured by walkerOS`}
  language="typescript"
/>

### Phase 2: Map dataLayer events to walkerOS destinations

<CodeSnippet
  code={`destinations: {
  ga4: {
    code: destinationGtag,
    config: {
      mapping: {
        // dataLayer events arrive as "dataLayer <event>"
        dataLayer: {
          purchase: {
            name: 'purchase',
            data: {
              map: {
                transaction_id: 'data.transaction_id',
                value: 'data.value',
                currency: 'data.currency',
              },
            },
          },
        },
      },
    },
  }
}`}
  language="typescript"
/>

### Phase 3: Gradually replace dataLayer.push with elb()

<CodeSnippet
  code={`// Old
dataLayer.push({ event: 'purchase', value: 99.99 });
// New
elb({ name: 'order complete', data: { value: 99.99 } });`}
  language="typescript"
/>
